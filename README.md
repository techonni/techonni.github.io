# Techonni studio hub

Static Astro site for [www.techonni.com](https://www.techonni.com).

## Stack

- Astro (static)
- Tailwind CSS v4
- GitHub Pages (`techonni/techonni.github.io`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to `main`. GitHub Actions builds and deploys Pages. Custom domain via `public/CNAME` → `www.techonni.com`.
