Why the Bauhaus set is 17 files, not a drop

A drop is a night. A set is a wall you live with. I wanted the second thing.

Most digital art shops sell a mood and a countdown. Buy this week. The file is gone next month. That model needs noise. I do not want noise on this desk.

The Bauhaus prints are seventeen separate JPEGs. Each one stands alone. Each one uses the same size, the same price, the same quiet frame. You can buy number four and never look at number twelve. That is the point of a set that is not a drop.

Why seventeen

Not because seventeen is magic. Because the grid on the shop is four across. Four rows would be sixteen. Seventeen leaves one print on the last row so the set still feels open. If I add more later, they sit under the same names: Bauhaus 18, and so on. The numbering is the catalogue, not a story you have to finish.

The work itself is a language: cream, black, navy, a little red, a little ochre. Circles, arches, lattices, one eye. Some pieces shout. Some only stack lines. Hung as a group they talk. Hung alone they still read as a poster, not as a missing page from a book.

Why files, not editions

An edition of fifty signed sheets needs storage, shipping, and a story about scarcity. I do not have a warehouse. I have a folder. The scarcity that matters is your wall, not my inventory.

A file also means you choose the paper. One person prints on cheap stock to test the colour. Another pays a lab once and frames it for years. Same JPEG. Different object. I sell the first half. You finish the second.

What a set asks of you

Do not print all seventeen in one weekend unless the room is empty. Pick two that share a colour. Hang them with air between the frames. Live with that pair for a month. If the wall still wants a third, the file is already on the disk.

That is why the shop is slow on purpose. No timer. No “only three left.” The files stay up. The bundle exists if you already know you want the language, not one poster. A drop would have forced a decision in an evening. A set lets the room decide.
